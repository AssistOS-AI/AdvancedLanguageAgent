Documentation / Execution

Execution backends, workspaces, and feedback

After routing selects an A-Skill, ALA chooses an executor that can meet its quality and capability requirements. The task method remains independent from a provider or authenticated tool.

Generic execution capabilities

Straightforward work normally uses direct model execution through LLMAgent. Cost and latency may be optimized only among executors considered capable of meeting the A-Skill's requirements.

CapabilityExecution responsibility
Direct LLMRuns a prompt through the configured LLMAgent.
Fast LLMPrefers an eligible low-latency, lower-cost model for sufficiently simple work.
Deep LLMUses an eligible stronger model when task quality requires deeper reasoning.
Coding agentDelegates bounded work to a supported authenticated agent CLI.
Agentic executionCoordinates multi-step planning, retries, validation, or synthesis.
Web and research accessRetrieves and checks external material when the task method requires it.
Temporary task workspaceIsolates inputs, intermediate artifacts, checks, and final outputs for one request.

Authenticated coding-agent CLIs such as Codex or OpenCode may perform language tasks as well as bounded code work. ALA invokes their supported interfaces and does not extract credentials. This path permits execution when a machine has an authenticated agent but no direct provider API key.

Task workspaces and feedback

An A-Skill may request a task workspace for explicit input, retrieved sources, intermediate artifacts, verification results, and final output. The task workspace is isolated and is not an implicit copy of the caller's repository.

Interactive sessions retain the selected task and previous result. Corrective feedback becomes an additional constraint, and every retry stops at a configured bound. A failed quality check may move execution from a fast model to a stronger model or to agentic execution.

Configuration discipline

Every direct model call uses LLMAgent with AchillesAgentLib-compatible model tags. Manual runtime values take precedence over environment-derived defaults. Documentation, specification, orchestration, bootstrap, and testing work use applicable metadata tags. DS002 contains the authoritative execution strategy.

Definitions

Agentic execution
A bounded multi-step run in which an agent can plan, retry, validate, and synthesize according to an A-Skill's method.
Task workspace
An isolated temporary directory created for one multi-stage request and limited to explicit task material and artifacts.
