ALA command reference

The ala executable lets a human or calling agent run one language request, retain an interactive conversation, or manage optional task repository registrations. General execution does not require a repository.

Execute a request

ala [options] [instruction...]

Positional words form the instruction. With no instruction in a terminal, ALA starts an interactive session. In a non-interactive pipeline with no positional instruction, standard input becomes the instruction. The command sends the composed prompt to MainAgent and writes the normalized result to standard output unless --output selects a file.

ala "Summarize the report" --file report.md
printf 'Summarize this text' | ala
ala --interactive

Execution options

OptionBehavior
--skill <name>Executes the named A-Skill explicitly. An unknown skill name produces repository exit code 4.
--task-repo <path>Adds one task repository for this invocation without saving it. The option may be repeated.
--text <text>Adds a labeled text payload. Repeated payload options retain their argument order.
--file <path>Reads one UTF-8 file relative to the current working directory and adds it as a payload.
--url <url>Retrieves one HTTP or HTTPS response as a UTF-8 payload with a 30-second timeout.
--stdinAdds standard input as a payload when a positional instruction is present. Without a positional instruction, standard input already supplies the instruction.
--output <path>Writes the result to the selected path instead of standard output.
--forceAllows --output to replace an existing file. Without this option, ALA refuses the overwrite.
--interactive, -iStarts or retains an interactive session. Enter :quit or :exit to close it.
--model <value>Selects a configured model name or semantic model value for this invocation.
--tag <tag>Adds a model-selection tag. The option may be repeated, and command-line tags replace ALA_TAGS.
--reasoning-effort <value>Overrides the reasoning effort forwarded to AchillesAgentLib.
--model-config <path>Resolves the path from the current working directory and supplies it to AchillesAgentLib through LLM_MODELS_CONFIG_PATH.
--achilles-path <path>Uses an explicit AchillesAgentLib module, package directory, or entry file before the normal dependency-resolution paths.
--config <path>Selects an ALA JSON configuration file relative to the current working directory.
--help, -hPrints usage and option help to standard output without starting the runtime.
--version, -vPrints the version from package.json to standard output.

Each file or URL payload is limited to 10 MiB, and all explicit payloads together are limited to 32 MiB. Diagnostics and interactive prompts use standard error so standard output remains usable by another program.

Add a task repository

ala repo add <path> [--config <path>] [--help]

This command resolves the repository to a canonical path, verifies that it contains at least one supported AchillesAgentLib skill descriptor, and stores it in the selected ALA configuration. Adding the same canonical path again is idempotent. The command prints the registered path and does not copy the repository.

List task repositories

ala repo list [--config <path>] [--json] [--help]

This command prints persistent repository paths from the selected configuration. The default output contains one path per line. --json writes a JSON array, including an empty array when no repository is registered.

Remove a task repository

ala repo remove <path> [--config <path>] [--help]

This command removes the matching canonical or lexical path from ALA configuration and prints the removed path. It does not delete the task repository or any files inside it. An unregistered path produces repository exit code 4.

Each repository command accepts --help and prints the common command reference without reading or changing configuration.

Configuration precedence

The ALA configuration path resolves in this order: --config, ALA_CONFIG_PATH, $XDG_CONFIG_HOME/ala/config.json, then ~/.config/ala/config.json. Model selection resolves command-line values before ALA_MODEL, ALA_TAGS, and ALA_REASONING_EFFORT, after which AchillesAgentLib applies its configured defaults.

For Soul Gateway, set SOUL_GATEWAY_BASE_URL and SOUL_GATEWAY_API_KEY in the process environment or in the first .env file AchillesAgentLib finds while walking upward from the current working directory. Use LLM_MODELS_CONFIG_PATH or --model-config to supply another model catalog.

Exit codes

CodeMeaning
0The command completed successfully.
2An option, command, or configuration value was invalid.
3ALA could not read an input or safely write the requested output.
4A task repository, A-Skill, or AchillesAgentLib dependency could not be resolved or validated.
5Runtime execution failed.
130The active execution was interrupted.
