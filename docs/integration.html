Documentation / Integration

Integration and evaluation

Advanced Language Agent (ALA) operates as a standalone command-line interface (CLI) and as a Ploinky agent. Ploinky is an agent-hosting environment that exposes registered agents through its CLI, router, and WebChat. A Ploinky deployment therefore makes the same ALA task interface available to terminal users, web-chat users, and other agents.

Deployment and configuration

Task repositories are configured independently from the ALA installation. AchillesAgentLib is the skill-based agent library used by ALA. It supplies the model configuration and semantic tags that map task requirements such as fast, deep, planning, coding, research, and long-context work to configured models. Task repositories are configured independently so a deployment can install only the task families it needs.

Evaluation paths

Routing evaluation compares explicit task selection, default selection by AchillesAgentLib's MainAgent coordinator, and symbolic-first selection. The evaluation corpus includes canonical instructions, paraphrases, multilingual requests, spelling errors, ambiguous and multi-step requests, missing parameters, and unsupported tasks. Results must report direct-routing accuracy, incorrect direct routing, abstention, fallback, and final correctness after fallback.

DS005 defines the deployment, workspace, retry, and evaluation requirements that an ALA integration must preserve.
