Documentation / Architecture

Runtime and task-repository architecture

ALA supplies general language execution and reusable execution services. Independent task repositories may add specialized domain methods through task skills. This boundary lets a task family evolve without extending the central runtime.

Responsibility boundary

A task repository decides which requests it covers, which task skill performs the work, which inputs and outputs are valid, and how the result is checked. ALA decides how the selected method runs in the current environment. It maps requested generic execution capabilities to configured models, authenticated agents, research access, or an isolated workspace.

AchillesAgentLib skill families

A task skill is an Anthropic-style declaration declared in SKILL.md and owned by a task repository. A Code Skill runs a supplied module. An Orchestration Skill coordinates several actions. A DBTable Skill describes table fields and operations. A Dynamic Code Generation Skill creates code during task execution. The owning repository selects the family that fits its method.

A task Code Skill can request the generic coding-agent executor through MainAgent while forwarding its ALA context and cancellation signal. This keeps Codex, OpenCode, and Pi invocation details in the core runtime and keeps the task method portable.

Discovery and portability

ALA combines persistent, environment-provided, and invocation-specific task repositories. It validates their SKILL.md declarations, rejects duplicate canonical task-skill names, and links every discovered skills directory into an isolated discovery registry. When a supported coding agent is detected, the registry also exposes ALA's generic delegation Code Skill. One MainAgent sees these runtime tools and the resulting skill catalog. The registry is removed when the runtime closes.

AchillesAgentLib is installed through the ploinky-agent-lib dependency in package.json. A manual path, ACHILLES_AGENT_LIB_PATH, and a sibling checkout remain supported before package resolution. Imported task skill instructions, code, pages, and specifications remain in the repository that owns them.
