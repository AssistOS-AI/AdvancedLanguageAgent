Architecture and task repositories

Advanced Language Agent (ALA) supplies the services needed to run language tasks: model calls, coding agents, web research, temporary workspaces, routing, and retries. ALA uses AchillesAgentLib, a JavaScript library that discovers and runs reusable agent skills. Independent task repositories supply A-Skills. An A-Skill is a reusable AchillesAgentLib skill that packages the instructions and optional code for one kind of work. Code Skills run repository-provided modules, Orchestration Skills coordinate multiple actions, DBTable Skills describe table operations, and Dynamic Code Generation Skills produce code during execution.

Boundary of responsibility

ALA decides how to execute a selected A-Skill in the current environment. It can call a large language model (LLM), invoke an authenticated coding agent, retrieve web sources, or create an isolated temporary workspace. The A-Skill decides what steps the task requires and how the result must be checked. For example, translation, reference verification, controlled-natural-language conversion, scientific writing, and planning with SOP Lang belong in A-Skills, not in the ALA runtime. SOP Lang is a language for expressing executable multi-step procedures.

What a task repository provides

Each task repository must describe the request types it covers, selection evidence, input and output expectations, available A-Skills, constraints, and verification procedures. It must also identify whether a skill needs a model, coding agent, research access, or temporary workspace. ALA uses the repository description when it selects a task, so the description affects routing as well as human documentation.

AchillesAgentLib integration point

AchillesAgentLib provides MainAgent, the coordinator that discovers skills, registers them, selects a matching skill, and sends it to the subsystem for its skill family. ALA uses this behavior for its default task selection and preserves compatible model tags and session behavior while exposing a simpler CLI to callers.

Imported skills remain local to their task repository. They do not become host-project DS files or standalone pages under this documentation tree.
