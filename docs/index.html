Advanced Language Agent

Advanced Language Agent (ALA) is a system-installed command-line interface for language and documentation tasks. It gives people and other agents one entry point for research, transformation, planning, and verification without requiring each caller to integrate language models and agent tools directly.

ALA uses AchillesAgentLib, a JavaScript library that discovers and runs reusable agent skills. ALA performs task-specific work through A-Skills. An A-Skill is an AchillesAgentLib skill installed through an independent task repository; it packages the instructions and optional code for one kind of work.

What the system does

A caller supplies an instruction and optional input. ALA selects an A-Skill, determines which execution service it needs, and returns the result through standard output or a file. An execution service is a language model, coding agent, research tool, or temporary workspace supplied by ALA. Routing diagnostics remain separate from the result. 

flowchart LR
      U[Caller] --> I[Instruction and payload]
      I --> R[Task or A-Skill routing]
      R --> C[Required execution service]
      C --> E[Model, agent, research, or workspace]
      E --> O[Result output]

AchillesAgentLib skill families

AchillesAgentLib provides several skill families for different execution needs. Code Skills run modules supplied by a task repository. Orchestration Skills coordinate multiple skills, tools, or agents across a multi-step task. DBTable Skills describe table fields and database operations. Dynamic Code Generation Skills generate and execute code when a task cannot be handled by a fixed module. A task repository selects the family that matches the work its A-Skills perform.
