Advanced Language Agent

Advanced Language Agent (ALA) is a system-installed CLI for language-oriented and documentation-oriented tasks. It gives callers one interface while independent A-Skills define task methodology.

What the system does

A caller supplies an instruction and optional payload. ALA selects a task repository or A-Skill, resolves generic execution requirements, and returns the result through standard output or a file. Routing diagnostics remain separate from the result.

flowchart LR
  U[Caller] --> I[Instruction and payload]
  I --> R[Task or A-Skill routing]
  R --> C[Generic ALA capability]
  C --> E[LLM or coding agent]
  E --> O[Result output]

Documentation map

Architecture defines the ALA boundary and task repositories. Routing describes MainAgent-compatible and symbolic-first selection. Execution covers models, agents, workspaces, feedback, and retries. Integration records configuration, Ploinky operation, and evaluation.

Rules and verification

DS001-coding-style.md is the canonical source for coding style, module layout, and modular test organization. The full specification set is available through the specification matrix. Source changes must update both these pages and the affected specifications.

Skill catalog

The host repository uses the gamp-specs documentation skill. A-Skills are supplied by independent task repositories and remain documented with those repositories.
